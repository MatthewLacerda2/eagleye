# Eagleye v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted service that grabs frames from camera feeds, skips unchanged ones, asks Claude Haiku 5.5 whether catalogued events are happening, stores every decision, alerts by webhook, and exposes an admin review page and Grafana metrics.

**Architecture:** One backend image runs two processes — `api` (FastAPI, template's 4 layers) and `worker` (asyncio rounds: capture → change filter → Claude → store → alert). Config is two YAML files synced into Postgres at worker start. The React admin reviews observations; Prometheus + Grafana (compose profile `monitoring`) read the worker's metrics and Postgres.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy async + asyncpg, Alembic, `anthropic` SDK, Pillow + NumPy, ffmpeg (subprocess), httpx, prometheus-client, PyYAML; React 19 + TanStack Router/Query + shadcn + Tailwind v4 + bun; Postgres 16 (pgvector image); Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-02-eagleye-design.md`

## Global Constraints

- Template rules hold (`CLAUDE.md`): DB access only in `repositories/`, repositories `flush()` and callers commit, Pydantic I/O on every `@router` handler, files ≤ 350 lines, handlers ≤ 50, tests ≤ 50, frontend design-system lint, i18n for every user-facing string (en, pt, es), English-only code and docs.
- `make check` green before every commit that touches code.
- Nothing in the repository names the first user, its clients, its camera vendor, vessel names, or contains a real camera URL or frame. Real config lives in `config/local/` (git-ignored).
- Model `claude-haiku-5-5`; `output_config={"effort": "medium", "format": {...}}`; omit `thinking`, `temperature`, `top_p`, `top_k`; non-streaming.
- Prompt layers: catalog in `system` with `cache_control {"type": "ephemeral", "ttl": "1h"}`; site block first user content block with the same marker; round content after, unmarked. No time/IDs/unsorted data in layers 1–2.
- `description` ≤ 100 characters (truncate on store).
- Default env values: `ROUND_INTERVAL_SECONDS=120`, `FRAME_MAX_SIDE=640`, `MAX_UNSENT_MINUTES=60`, `MAX_CAMERAS_PER_CALL=20`, `ANALYSIS_MAX_TOKENS=4000`, `KEEPALIVE_ENABLED=true`, `KEEPALIVE_AFTER_MINUTES=55`, `DAILY_BUDGET_USD=25`, `ALERT_COOLDOWN_MINUTES=10`, `RETENTION_DAYS=14`, prices Haiku 5.5 input $0.10/MTok, output $0.50/MTok, cache read 0.1×, cache write 1h 2×.
- Postgres host port **5442** (5432 is often taken on a dev machine); `DATABASE_URL` default `postgresql+asyncpg://postgres:postgres@localhost:5442/eagleye`.
- License Apache-2.0.

## Review Focus

1. **Camera offline / ffmpeg hangs** — a dead URL or stalled HLS must time out (`CAPTURE_TIMEOUT_SECONDS=20`), mark the camera offline, and never stall the round for other cameras. Test in Task 4.
2. **Model returns a camera key it was not asked about, an unknown event key, or malformed JSON / `stop_reason` `refusal` or `max_tokens`** — store a failed analysis, never crash the worker, never create observations for unknown cameras. Test in Task 6.
3. **Worker restart mid-PoC** — config re-sync must not duplicate sites/cameras or orphan history; a camera removed from YAML is disabled, not deleted. Test in Task 3.
4. **Budget cap crossing UTC midnight** — the cap uses today's UTC sum; calls resume on the new day without a restart. Test in Task 8.
5. **Frame file missing on disk** (retention ran, volume wiped) — the frame endpoint returns 404, the admin shows a placeholder, no 500. Test in Task 9.

### Task 5: Change filter with auto-mask

**Files:**
- Create: `backend/services/change_filter.py`
- Test: `backend/tests/services/test_change_filter.py`

**Interfaces — Produces:**
- `cell_diffs(a: ndarray, b: ndarray, cols: int, rows: int) -> ndarray` — per-cell mean absolute difference, shape `(rows, cols)`; resizes `b` to `a`'s shape if they differ.
- `ignore_mask(shape_rows: int, shape_cols: int, rects: list[Rect]) -> ndarray[bool]` — cells overlapping any rect.
- `@dataclass CameraChangeState(last_capture: ndarray | None, last_sent: ndarray | None, last_sent_at: datetime | None, history: deque[ndarray[bool]])` — `history` has `maxlen=AUTOMASK_WINDOW`.
- `ChangeDecision(send: bool, reason: Literal["first","changed","stale","unchanged"], changed_cells: int)`
- `ChangeFilter(settings)`; `.decide(state: CameraChangeState, thumb: ndarray, ignore: list[Rect], now: datetime) -> ChangeDecision` — (1) if `last_capture` exists, append `cell_diffs(last_capture, thumb) > threshold` to `history`; set `last_capture = thumb`. (2) `auto = mean(history) > AUTOMASK_RATIO` once `len(history) >= AUTOMASK_MIN_SAMPLES`, else all False. (3) `last_sent is None` → `first`; `now - last_sent_at > MAX_UNSENT_MINUTES` → `stale`; changed cells vs `last_sent`, excluding `auto | ignore_mask`, ≥ `CHANGE_MIN_CELLS` → `changed`; else `unchanged`. Does **not** set `last_sent` — `.mark_sent(state, thumb, now)` does, after the frame is actually sent.

### Task 8: Worker, metrics, budget, keep-alive, retention

**Files:**
- Create: `backend/worker/__init__.py`, `backend/worker/__main__.py` (entry: `python -m worker`), `backend/worker/rounds.py`, `backend/worker/loops.py`, `backend/services/metrics.py`
- Test: `backend/tests/worker/test_rounds.py`, `test_loops.py`

**Interfaces — Consumes:** Tasks 2–7. **Produces:**
- `metrics` module-level prometheus objects (names prefixed `eagleye_`): `captures_total{result}`, `capture_seconds` (histogram), `frames_skipped_total{reason}`, `frames_sent_total`, `analyses_total{kind,status}`, `tokens_total{type}` (`input`/`cache_read`/`cache_write`/`output`), `cost_usd_total`, `analysis_seconds` (histogram), `observations_events_total{event}`, `alerts_total{status}`, `budget_paused` (gauge 0/1), `cameras_online` (gauge).
- `rounds.RoundDeps(session_factory, grab, prepare, change_filter, analyzer, alert_sender, catalog, settings, clock)` — `grab`/`clock` injectable for tests.
- `rounds.run_site_round(deps, site_id: uuid.UUID, states: dict[uuid.UUID, CameraChangeState]) -> RoundReport(captured: int, offline: int, sent: int, analysis_ids: list[uuid.UUID])` — capture all enabled cameras concurrently (semaphore `CAPTURE_CONCURRENCY`), set statuses, filter, skip analysis if budget reached (`spent_usd_since(today 00:00 UTC) >= DAILY_BUDGET_USD`), chunk by `MAX_CAMERAS_PER_CALL`, analyze, write frames + rows in one transaction per analysis, `mark_sent` only for frames of a successful analysis, then alerts, then metrics.
